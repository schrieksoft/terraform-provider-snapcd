# snapcd_namespace_terraform_inline_policy (Data Source)

Use this data source to access information about an existing Namespace Terraform Inline Policy in Snap CD.

## Required permissions

Any of: `Organization.Contributor`, `Organization.Owner`, `Organization.Reader`, `Organization.StackContributor`, `Organization.StackReader`, `Stack.Contributor`, `Stack.Owner`, `Stack.Reader`, `Namespace.Contributor`, `Namespace.Owner`, `Namespace.Reader`


## Example Usage

```terraform
data "snapcd_stack" "mystack" {
  name = "mystack"
}

data "snapcd_namespace" "mynamespace" {
  name     = "mynamespace"
  stack_id = data.snapcd_stack.mystack.id
}
data "snapcd_namespace_terraform_inline_policy" "mypolicy" {
  name         = "mypolicy"
  namespace_id = data.snapcd_namespace.mynamespace.id
}
```
