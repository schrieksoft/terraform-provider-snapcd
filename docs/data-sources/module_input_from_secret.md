# snapcd_module_input_from_secret (Data Source)

Use this data source to access information about an existing Module Input (From Secret) in Snap CD.

## Required permissions

Any of: `Organization.Contributor`, `Organization.Owner`, `Organization.Reader`, `Organization.StackContributor`, `Organization.StackReader`, `Stack.Contributor`, `Stack.Owner`, `Stack.Reader`, `Namespace.Contributor`, `Namespace.Owner`, `Namespace.Reader`, `Module.Owner`, `Module.Reader`


## Example Usage

```terraform
data "snapcd_stack" "mystack" {
  name = "mystack"
}

data "snapcd_namespace" "mynamespace" {
  name     = "mynamespace"
  stack_id = data.snapcd_stack.mystack.id
}
data "snapcd_module" "mymodule" {
  name         = "mymodule"
  namespace_id = data.snapcd_namespace.mynamespace.id
}
data "snapcd_module_input_from_secret" "myvar" {
  input_kind = "Param"
  name       = "myvar"
  module_id  = data.snapcd_module.mymodule.id
}
```
