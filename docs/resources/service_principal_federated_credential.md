# snapcd_service_principal_federated_credential (Resource)

Manages a Federated Credential on a Service Principal in Snap CD.

A workload presenting a token from the given issuer, carrying the given subject and audience, authenticates as the Service Principal. No client secret is involved, so nothing secret appears in this configuration or in Terraform state.

The Server must be able to reach the issuer to fetch its signing keys. For a Kubernetes ServiceAccount the subject is `system:serviceaccount:{namespace}:{name}`.

## Required permissions

Any of: `Organization.IdentityAccessManager`, `Organization.Owner`


## Example Usage

```terraform
# Lets a Kubernetes ServiceAccount authenticate as the Service Principal with its projected
# token, so no client secret is deployed with the Runner.
resource "snapcd_service_principal" "runner" {
  client_id = "runner-prod"
}

resource "snapcd_service_principal_federated_credential" "runner_cluster" {
  service_principal_id = snapcd_service_principal.runner.id
  name                 = "prod-cluster"

  # The cluster's OIDC issuer. The Snap CD Server must be able to reach it.
  issuer   = "https://oidc.eks.eu-west-1.amazonaws.com/id/EXAMPLE"
  subject  = "system:serviceaccount:snapcd/snapcd-runner"
  audience = "snapcd"
}
```

## Schema

### Required

- `audience` (String) Audience (`aud`) the presented token must carry. Normally `snapcd`.
- `issuer` (String) Issuer the presented token must come from, and where its signing keys are published. An absolute https URL, for example a Kubernetes cluster's OIDC issuer.
- `name` (String) Name of the Federated Credential. Must be unique within the Service Principal.
- `service_principal_id` (String) ID of the Service Principal this credential authenticates as.
- `subject` (String) Subject (`sub`) the presented token must carry. For a Kubernetes ServiceAccount this is `system:serviceaccount:{namespace}:{name}`.

### Optional

- `is_disabled` (Boolean) Indicates whether the Federated Credential is disabled. A disabled credential is not accepted.

### Read-Only

- `id` (String) Unique ID of the Federated Credential.
