# snapcd_namespace_pulumi_flag (Resource)

Manages a Namespace Pulumi Flag in Snap CD.

## Required permissions

## Example Usage

```terraform

  namespace_id = snapcd_namespace.mynamespace.id
  task         = "Plan"
  flag         = "Refresh"

}
```
