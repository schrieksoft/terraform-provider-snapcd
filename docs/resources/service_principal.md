# snapcd_service_principal (Resource)

Manages a Service Principal in Snap CD.

The Service Principal is created without a client secret, and this resource cannot set one: a secret managed through Terraform would be written to state by whatever generates it and whatever consumes it. Give it a `snapcd_service_principal_federated_credential` instead, so the workload authenticates with a token its own platform issues and no secret exists.

A secret can still be set in the Dashboard for a Service Principal that is not managed here.

## Required permissions

Any of: `Organization.IdentityAccessManager`, `Organization.Owner`


## Example Usage

```terraform
# Created without a client secret. Give it a federated credential so the workload can
# authenticate with a token its own platform issues.
resource "snapcd_service_principal" "runner" {
  client_id = "runner-prod"
}

resource "snapcd_service_principal_federated_credential" "runner_cluster" {
  service_principal_id = snapcd_service_principal.runner.id
  name                 = "prod-cluster"

  issuer   = "https://oidc.eks.eu-west-1.amazonaws.com/id/EXAMPLE"
  subject  = "system:serviceaccount:snapcd/snapcd-runner"
  audience = "snapcd"
}
```
