# snapcd_output_namespace_supply (Resource)

Manages an Output Namespace Supply in Snap CD.

## Required permissions

Any of: `Organization.Contributor`, `Organization.Owner`, `Organization.StackContributor`, `Stack.Contributor`, `Stack.Owner`, `Namespace.Contributor`, `Namespace.Owner`, `Module.Owner`


## Example Usage

```terraform
data "snapcd_stack" "mystack" {
  name = "mystack"
}

resource "snapcd_namespace" "producers" {
  name     = "producers"
  stack_id = data.snapcd_stack.mystack.id
}

resource "snapcd_namespace" "consumers" {
  name     = "consumers"
  stack_id = data.snapcd_stack.mystack.id
}

data "snapcd_runner" "myrunner" {
  name = "myrunner"
}

resource "snapcd_module" "producer" {
  name                = "producer"
  namespace_id        = snapcd_namespace.producers.id
  source_revision     = "main"
  source_url          = "https://github.com/schrieksoft/snapcd-samples.git"
  source_subdirectory = "getting-started/two-module-dag/module1"
  runner_id           = data.snapcd_runner.myrunner.id

  # Nothing downstream reads these Outputs unless they are supplied explicitly.
  output_set_downstream_restriction = "All"
}

resource "snapcd_module" "consumer" {
  name                = "consumer"
  namespace_id        = snapcd_namespace.consumers.id
  source_revision     = "main"
  source_url          = "https://github.com/schrieksoft/snapcd-samples.git"
  source_subdirectory = "getting-started/two-module-dag/module2"
  runner_id           = data.snapcd_runner.myrunner.id
}

resource "snapcd_output_namespace_supply" "vpc_id_to_consumers" {
  module_id              = snapcd_module.producer.id
  output_name            = "vpc_id"
  consuming_namespace_id = snapcd_namespace.consumers.id
}
```

## Schema

### Required

- `consuming_namespace_id` (String) ID of the Namespace the Output is supplied to, reaching every Module in it. Must be unique in combination with `module_id` and `output_name`.
- `module_id` (String) ID of the Module that produces the Output.
- `output_name` (String) Name of the Output being supplied.

### Read-Only

- `id` (String) Unique ID of the OutputNamespaceSupply.
